# WanThreadsApi

Halaman callback (redirect URI) untuk login Threads API akaun PitsStore.

- URL: https://wakketariblues.github.io/WanThreadsApi/
- Halaman hanya memaparkan kod login sekali-guna kepada pemilik akaun untuk disalin.

**Repo ini TIDAK menyimpan sebarang API key, App Secret atau token.**
Semua kunci disimpan secara setempat di komputer pemilik sahaja.
